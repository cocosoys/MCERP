# 03 · 核心功能

本文介绍 MCERP 已内置的后台功能模块及其后端实现要点。

## 1. 功能清单

| 菜单 | 模块 | 说明 |
| --- | --- | --- |
| 仪表盘 | `/` | 统计面板：主模块数、附属模块数、总模块数、目录/菜单/按钮数、模块列表 |
| 系统管理 | 用户管理 | 用户增删改查、状态切换、权限分配（菜单权限树 + 按钮权限）、重置密码、个人信息 |
| 系统管理 | 菜单管理 | 菜单树维护（M 目录 / C 菜单 / F 按钮）、分配权限 |
| 系统管理 | 字典管理 | 字典类型 + 字典数据 |
| 系统管理 | 参数设置 | 参数配置（如 `sys.user.initPassword` 初始密码） |
| 系统管理 | 公告通知 | 公告增删改查 |
| 系统管理 | 日志管理 | 操作日志 + 登录日志（成功/失败） |

> 附属 ERP 模块（`McerpExpansion`）的菜单会实时并入左侧菜单树与路由表，
> 详见 [04-扩展开发](04-扩展开发.md)。

## 2. 控制器与分层规范

本项目强制以下分层与书写规范：

- **Controller 零逻辑**：控制器只做参数接收与委托，具体实现全部在 Service 抽象层 → Impl 实现层；
- **禁 Map 拼实体**：返回数据一律实体化（`entity/vo`），禁止临时 `Map<String,String>` 手撕组装；
- **`@RequestBody` 禁 String**：必须使用实体类接收（`ErpUser`、`ChangeStatusVO` 等），杜绝手写 body 解析；
- **实体名 = 表名**：`ErpUser` ↔ `erp_user`，`ErpMenu` ↔ `erp_menu`；
- **VO 属性用表字段名**：如 `menuId/menuName/menuType/parentId/orderNum/path/component/perms/icon/visible/status`；
- **时间字段**：统一 `yyyy-MM-dd HH:mm:ss`，实体字段 `Date` + `@JsonFormat(pattern = BeanCodec.DATE_TIME_PATTERN)`，
  且业务实体继承 `BaseEntity`（自带 createTime/updateTime/createBy/updateBy/remark）；
- **权限标识带插件前缀**：如 `mcerp:system:user:add`；
- **i18n**：文案统一 `McerpI18n.t("mcerp.xxx", "中文回退", args...)`。

## 3. 用户与权限

- 用户表 `erp_user`：`userId` 为 `BIGINT AUTO_INCREMENT`；`userName` 与主插件凭证主体（玩家名）对应。
- **首次进入自动登记**：任何玩家第一次通过 SOYS 登录访问 ERP 时，`currentPlayer()` 会将其自动登记到 `erp_user`，
  便于后续按钮权限分配。
- 权限分配（用户管理 → 分配权限）：以菜单树为骨架（与若依前端一致），勾选目录/菜单/按钮后保存到用户权限；
  权限的 CURD 全部基于主插件 SOYSHTTPOverMC 的 local 权限存储，MCERP 只做展示与落库。
- **OP 默认全权限**：主插件权限镜像对 OP 放行一切 API。

## 4. 菜单管理

菜单表字段（与实体 `ErpMenu`、VO `ErpMenuVO` 一致）：

| 字段 | 说明 |
| --- | --- |
| `menuId` | 主键（BIGINT AUTO）；`ErpMenuVO` 中为 String，承载表主键/插件声明 id/合成键 |
| `parentId` | 父菜单 id（顶层 `0`） |
| `menuName` | 菜单名称 |
| `orderNum` | 排序号（小在前） |
| `path` | 路由地址（相对父级） |
| `component` | 组件路径/页面地址（C 菜单为页面组件或 iframe 目标） |
| `query` / `routeName` | 路由参数 / 路由名称 |
| `isFrame` / `isCache` | 是否外链 / 是否缓存 |
| `menuType` | `M` 目录 / `C` 菜单 / `F` 按钮 |
| `perms` | 权限标识 |
| `icon` / `visible` / `status` | 图标 / 显示状态 / 菜单状态 |
| `builtin` | `Y` 内置初始化数据 / `N` 运行时自定义 |

## 5. 字典 / 参数 / 公告

- 字典：`erp_dict_type`（类型）+ `erp_dict_data`（数据），前端字典下拉均走这两个表；
- 参数：`erp_config`，如 `sys.user.initPassword`（新增用户初始密码）；
- 公告：`erp_notice`，公告列表/详情。

## 6. 仪表盘统计面板

`ErpDashboardServiceImpl` 实时统计：

- 主模块数量（MCERP 自身）；
- 附属模块数量（已登记的 `McerpExpansion` 模块数）；
- 总模块数；
- 目录数（M）/ 菜单数（C）/ 按钮数（F）；
- 模块列表（id + 显示名 + 菜单数）。

> 已彻底移除 RuoYi 首页（欢迎页/文档入口），首页即统计面板；footer 默认隐藏。
