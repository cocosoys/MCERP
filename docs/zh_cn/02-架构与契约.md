# 02・架构与契约

本文说明 MCERP 的总体架构、请求链路、前端契约（`__SOYS_CONTEXT__.js`）以及登录鉴权模型。

## 1. 总体架构



```
浏览器

&#x20; │  https://\<host>:\<port>/web/plugins/MCERP/index

&#x20; ▼

SOYSHTTPOverMC 网关（HTTP-Over-MC 隧道，Spigot 1.12.2）

&#x20; ├─ 注解式 API 注册表（ApiRegistry）

&#x20; │    └─ /api/plugins/MCERP/prod-api/\*   → MCERP 控制器

&#x20; │    └─ /api/plugins/<模块ID>/\*          → 附属 ERP 模块控制器

&#x20; ├─ 页面托管（/web/plugins/\*）

&#x20; │    └─ dist/ 前端静态资源 + \_\_SOYS\_CONTEXT\_\_.js 契约注入

&#x20; ├─ auth 登录链路（/api/auth/login|logout|me|status|mode）

&#x20; ├─ 权限镜像（Bukkit 权限 → API 权限）

&#x20; └─ 事件总线（GatewayLoginResultEvent / GatewayCredentialIssuedEvent / ...）

&#x20;      └─ MCERP 旁路监听：登录日志、模块索引重建
```



* **MCERP 是主插件&#x20;**`SoysExpansion.REGISTERED`**&#x20;的投影者**：它不自己管理模块生命周期，

  只维护 "当前有哪些 ERP 模块" 的轻量索引（identifier → owner 插件名），模块内容

  （菜单、路由）在合成时**实时**从 REGISTERED 反查实例组装 —— 单一事实源、无缓存残留。

* **附属 ERP 模块**是继承 `McerpExpansion`（见 [04 - 扩展开发](04-扩展开发.md)）的独立插件，

  通过 `instanceof McerpExpansion` 被识别并登记。

## 2. 请求链路（以 "新增用户" 为例）



```
前端（RuoYi-Vue2，dist 内）

&#x20; POST /api/plugins/MCERP/system/user     ← apiBase 来自契约，无需手写

&#x20;     │  Authorization: Bearer \<token>

&#x20;     ▼

SOYS 网关 ApiRegistry.dispatch()

&#x20; ├─ 解析凭证（Bearer/Cookie/X-API-Key）

&#x20; ├─ 绑定请求上下文 ApiRequestContext.bind(ctx)  ← 供操作日志等免签名读取

&#x20; ├─ 权限判定（@ApiPermission / @ApiPublic / 默认拒绝）

&#x20; ▼

ErpUserController.add()   （薄层，零逻辑）

&#x20; ▼

ErpUserService.add()      （抽象层）

&#x20; ▼

ErpUserServiceImpl.add()  （实现层：事务 + 业务逻辑 + 操作日志 record）

&#x20; ▼

DATA.insert(ErpUser)      → erp\_user.yml / erp\_user 表
```

## 3. 前端契约（`__SOYS_CONTEXT__.js`）

主插件 ContractInjector 在伺服 `dist/index.html` 时，把脚本中的占位符替换为服务器环境原语：



```
// 伺服时替换 \_\_SOYS\_CONTEXT\_\_ 为：

// { "scheme":"http|https", "host":"...", "port":8080,

//   "apiPrefix":"/api", "pluginsPrefix":"/plugins/MCER",

//   "fullPrefix":"/api/plugins/MCER",

//   "pagePrefix":"/plugins/MCER", "webResourcePrefix":"web/plugins/MCER/page/" }

window.SOYS\_CONTEXT = typeof \_\_SOYS\_CONTEXT\_\_ !== 'undefined' ? \_\_SOYS\_CONTEXT\_\_ : null;

// HTML 资源引用改写排除列表：/prod-api 为应用 API 前缀，/api 为 SOYS 保留前缀

window.SOYS\_CONTEXT\_EXCLUDES = \["/prod-api", "/api"];
```

**意义**：把插件连同前端复制到另一台服务器时，前端代码无需任何改动 ——

apiBase（`/api`）、页面前缀（`/web/plugins/MCERP`）、host/port 全部运行时自适应。

这正是 "一组前端代码换服务器即用" 的根基。

前端生产构建的关键配置（`vue.config.js`）：



```
publicPath: process.env.NODE\_ENV === "production" ? "/web/plugins/MCERP/" : "/",
```

> publicPath 只写相对服务器的绝对路径（不写 host/port）；host/port 由契约运行时补齐。

## 4. 登录鉴权模型

**MCERP 不自行实现 auth**，登录 / 登出 / 验证码 / 会话全部交给主插件：



| 端点                                           | 说明                                    |
| -------------------------------------------- | ------------------------------------- |
| `POST /api/auth/login`                       | 弹窗登录（AuthMe 密码校验或免密码直登）               |
| `POST /api/auth/issue`                       | 票据登录（游戏内链接）                           |
| `GET /api/auth/status`                       | 会话状态（含 "记住我" 设备凭证自动登录 / 游戏 IP 匹配自动登录） |
| `GET /api/auth/me` / `POST /api/auth/logout` | 当前用户 / 退出                             |



* 前端登录 / 跳转逻辑复用主插件提供的 `soys-auth.js`（Bearer token 注入、401 跳登录页）。

* MCERP 只保留若依前端契约的两个只读端点：


  * `GET /api/plugins/MCERP/auth/getInfo`：当前登录者信息（user/roles/permissions）；

  * `GET /api/plugins/MCERP/auth/getRouters`：当前登录者可见路由树（菜单表 ⊕ 插件登记模块）。

**权限模型**：



* API 权限 = 主插件权限镜像：`@ApiPermission("mcerp:xx")` 要求调用者拥有对应 Bukkit 权限；

* **OP 默认拥有所有权限**（主插件权限 store 按 OP 放行）；

* 前端菜单可见性由 `getRouters` 返回的路由树决定，路由树按调用者权限过滤。

## 5. 目录与前缀速查



| 概念                | 值                                                                    |
| ----------------- | -------------------------------------------------------------------- |
| API 前缀            | `/api`（主插件 apiPrefix）                                                |
| MCERP API 根       | `/api/plugins/MCERP`                                                 |
| 页面托管根             | `/web/plugins/MCERP`                                                 |
| 附属模块页面根           | `/web/plugins/<模块ID>`（`pageRoot()`）                                  |
| 菜单 component 默认前缀 | `/web/plugins/<模块ID>/<安全目录名>`（`pageDirRoot()`，identifier 过滤非法字符并转小写） |
| 存储目录              | `plugins/SOYSHTTPOverMC/data/*.yml`（YAML 模式）                         |

> `NameSafe.path()`
>
> ：只保留字母 / 数字 / 下划线并转小写，例如 
>
> `SOYSHTTPOverMC-ERP`
>
>  → 
>
> `soyshttpovermcerp`
>
> 。
