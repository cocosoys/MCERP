# 04・扩展开发（附属 ERP 模块）

MCERP 的核心扩展方式：**附属插件继承&#x20;**`McerpExpansion`**（它继承主插件&#x20;**`SoysExpansion`**）**，

只需覆写 ERP 声明钩子并调用一行 `register()`，即可自动完成 API 注册、页面托管、

数据初始化、菜单 / 路由登记 —— 即安即生效，卸载同步摘除。

## 1. 最小示例



```
package com.example.stock;

import com.github.cocosoys.mc.mcerp.ErpMenus;

import com.github.cocosoys.mc.mcerp.McerpExpansion;

import org.bukkit.plugin.java.JavaPlugin;

public class StockPlugin extends JavaPlugin {

&#x20;   @Override

&#x20;   public void onEnable() {

&#x20;       // 一行注册：SoysExpansion 骨架自动执行端点登记 + 页面托管 + 数据初始化；

&#x20;       // 本类 onRegister() 自动把模块（identifier/displayName/menus）登记进 MCERP ErpRegistry。

&#x20;       if (!new StockExpansion().register()) {

&#x20;           getLogger().warning("stock 注册失败（identifier 冲突 / bootstrap 未就绪）");

&#x20;       }

&#x20;   }

}

public class StockExpansion extends McerpExpansion {

&#x20;   @Override

&#x20;   public String getIdentifier() {

&#x20;       return "stock"; // 唯一必填元信息：决定 /api/plugins/stock/\* 与 /web/plugins/stock/\* 前缀

&#x20;   }

&#x20;   @Override

&#x20;   protected String displayName() {

&#x20;       return "库存管理";

&#x20;   }

&#x20;   @Override

&#x20;   protected int sortOrder() {

&#x20;       return 20; // 模块在左侧菜单中的排序

&#x20;   }

&#x20;   @Override

&#x20;   protected ErpMenus menus() {

&#x20;       return ErpMenus.create()

&#x20;           .dir("system", "系统管理", "system", d -> d

&#x20;               .menu("user", "用户列表", "user").perm("soys.erp.user.list")

&#x20;               .menu("group", "权限组列表", "lock"))

&#x20;           .menu("home", "首页", "home").component("erp/home");

&#x20;   }

&#x20;   @Override

&#x20;   protected String\[] dataRoots() {

&#x20;       return new String\[]{"data"}; // 可选：释放 resources/data/\*.yml 作为初始化数据

&#x20;   }

}
```

## 2. 可覆写钩子（全部可选，除 getIdentifier 外）



| 钩子                                                              | 默认                | 说明                                             |
| --------------------------------------------------------------- | ----------------- | ---------------------------------------------- |
| `getIdentifier()`                                               | —                 | **唯一必填**：模块标识，决定 API / 页面前缀                    |
| `displayName()`                                                 | identifier        | 左侧菜单显示的模块名                                     |
| `icon()`                                                        | null              | 模块图标                                           |
| `sortOrder()`                                                   | 0                 | 模块排序                                           |
| `permission()`                                                  | null              | 主菜单访问权限标识                                      |
| `homeUrl()`                                                     | null              | 无子菜单时的默认页地址                                    |
| `menus()`                                                       | null              | 声明式菜单树（`ErpMenus` DSL，与 `menusTable()` 二选一，优先） |
| `menusTable()`                                                  | null              | 直接返回 `List&lt;ErpMenuVO&gt;` 树（自行 new 拼接）      |
| `wujie()`                                                       | true              | 子应用渲染模式：true=wujie 微前端 /false = 传统 iframe      |
| `dataRoots()` / `sqlRoots()` / `seedData()` / `schemaVersion()` | 继承自 SoysExpansion | 数据初始化（见 05 - 数据与初始化）                           |
| `resourceRoot()` / `indexFallbackEnabled()` / `spaFallback()`   | 继承自 SoysExpansion | 页面托管                                           |

## 3. 菜单 DSL（`ErpMenus`）

方法名定节点类型：`dir`=M 目录、`menu`=C 菜单、`perm`=F 按钮权限、`route`=path→component 便捷 C 菜单。

### 3.1 lambda 嵌套（推荐，最接近 YAML 缩进）



```
return ErpMenus.create()

&#x20;   .dir("system", "系统管理", "system", d -> d        // 目录，lambda 内为子级

&#x20;       .menu("user", "用户列表", "user")              // 叶子菜单

&#x20;           .perm("soys.erp.user.list")               // 按钮（挂到当前层级）

&#x20;           .perm("soys.erp.user.add")

&#x20;       .menu("group", "权限组列表", "lock"))

&#x20;   .menu("home", "首页", "home").component("erp/home"); // 顶层叶子
```

### 3.2 流式 + up ()



```
return ErpMenus.create()

&#x20;   .dir("system", "系统管理", "system")   // 进入子级上下文

&#x20;       .menu("user", "用户列表", "user")

&#x20;       .menu("group", "权限组列表", "lock")

&#x20;   .up()                                 // 返回上一级

&#x20;   .menu("home", "首页", "home").component("erp/home");
```

### 3.3 全属性 spec（所有表字段一次填齐）



```
return ErpMenus.create()

&#x20;   .dir(s -> s.menuId("system").menuName("系统管理").icon("system").orderNum(1), d -> d

&#x20;       .menu(m -> m.menuId("user").menuName("用户列表").icon("user")

&#x20;           .perms("soys.erp.user.list").orderNum(10).component("erp/user").visible(true))

&#x20;       .perm(p -> p.menuId("user:add").menuName("新增用户").perms("soys.erp.user.add")))

&#x20;   .route("stock/io", "erp/io").perms("stock:io:list");
```

`MenuSpec` 支持全部表字段：`menuId/menuName/parentId/orderNum/path/component/componentFull/componentFullURL/`

`query/routeName/isFrame/isCache/menuType/visible/status/perms/icon/builtin`。

### 3.4 component 免写（自动拼接）



* `component("erp/user")` → 自动拼 `pageDirRoot()` = `/web/plugins/<模块ID>/<安全目录名>/erp/user`；

* `componentFull("xxx")` → 只补 `/web/plugins/<模块ID>`；

* `componentFullURL("https://example.com/page")` → 不拼任何前缀（外链）；

* **完全不写 component**：C 菜单按 `basePrefix + 父级 dir 链 + "/" + menuId` 自动拼接

  （如 `dir("config") > dir("dict") > menu("type")` → `/web/plugins/<id>/<安全名>/config/dict/type`）。

## 4. 自动按钮（Controller → F 按钮）

菜单下的按钮无需手写：给 `menu()` 传入 controller 类，或链式 `permsFrom(Class...)`，

`ControllerPermScanner` 会按下列规则自动把端点方法投影为 F 按钮：



| 规则        | 行为                                                                           |
| --------- | ---------------------------------------------------------------------------- |
| 端点判定      | 方法上存在 `@GetMapping/@PostMapping/@PutMapping/@DeleteMapping` 之一               |
| 按钮名       | 方法级 `@ApiName` → 类级 `@ApiName` → Java 方法名                                    |
| 权限        | 方法级 `@ApiPermission` → 类级 `@ApiPermission`；`@ApiPublic`（方法级或类级）时按钮不设权限（登录即可） |
| 默认拒绝端点    | 既无 `@ApiPermission` 又无 `@ApiPublic`（网关默认 403）→ 不生成按钮                         |
| `@Hidden` | 方法级或类级 → 跳过，不生成按钮                                                            |
| menuId    | 有权限用权限串；`@ApiPublic` 无权限用 Java 方法名                                           |
| 排序        | 按方法声明顺序递增                                                                    |



```
return ErpMenus.create()

&#x20;   .dir("system", "系统管理", "system", d -> d

&#x20;       .menu("user", "用户列表", "user", ErpUserController.class) // 按钮自动生成

&#x20;       .menu("group", "权限组列表", "lock").permsFrom(ErpGroupController.class))

&#x20;   .menu("home", "首页", "home").component("erp/home");
```

## 5. 生命周期与索引重建



* **登记**：`McerpExpansion.onRegister()`（SoysExpansion 注册骨架回调）→ 写入 `ErpRegistry` 索引；

* **摘除**：`onUnregister()` / 插件禁用（`PluginDisableEvent`）→ 移除索引，卸载同步清理；

* **判定**：`instanceof McerpExpansion`（宿主 `McErpHostExpansion` 是 `SoysExpansion` 直系子类，天然排除）；

* **兜底重建**：`/mcerp reload` 与 `/soyshttp reload`（`registerReloadHook`）以及服务器完全启动后的一次扫描，

  都会以 `SoysExpansion.REGISTERED` 为准清理残留索引并补登记。

## 6. 页面托管与微前端



* 附属插件的静态资源放在 `resources/dist/`，经 `resourceRoot()` 声明由主插件托管于 `/web/plugins/<模块ID>/`；

* 菜单默认以 **wujie（无界微前端）** 模式嵌入 MCERP 主应用（`wujie()` 返回 true）：

  子应用需配合 history 路由 + 绝对 publicPath + 空 Layout（不渲染自己的登录页与侧边栏）；

* 若 `wujie()` 返回 false，则退回传统 iframe 模式。

> 详见 06 - 前端定制与微前端。
