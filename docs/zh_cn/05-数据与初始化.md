# 05・数据存储与初始化

MCERP 使用**实体注解驱动**的存储层（主插件 dlz 实体引擎），同一套实体同时支持

**YAML 文件模式**与 **SQL 模式**（MySQL / SQLite）。8 张业务表主键统一 `BIGINT AUTO_INCREMENT`。

## 1. 存储模式



| 模式   | 初始化来源                                        | 运行时数据位置                                |
| ---- | -------------------------------------------- | -------------------------------------- |
| YAML | `src/main/resources/data/*.yml` → 释放到主插件数据目录 | `plugins/SOYSHTTPOverMC/data/<表名>.yml` |
| SQL  | `src/main/resources/sql/mcerp-init.sql`      | 数据库表（按实体自动建表）                          |



* 主插件 `config.yml` 的 `storage.backends.mysql / sqlite` 决定启用哪种后端；

* SQL 后端装配后，表会按实体注解自动创建，`mcerp-init.sql` 用于独立建库 / 建表场景，

  `CREATE TABLE IF NOT EXISTS` 可重复执行；初始数据 `INSERT IGNORE`（SQLite 用 `INSERT OR IGNORE`）不产生重复。

## 2. 数据表清单（8 张）



| 表                | 实体              | 说明                                              |
| ---------------- | --------------- | ----------------------------------------------- |
| `erp_menu`       | `ErpMenu`       | 菜单表（内置初始化数据 `builtin='Y'`，运行时自定义 `builtin='N'`） |
| `erp_config`     | `ErpConfig`     | 参数配置                                            |
| `erp_dict_type`  | `ErpDictType`   | 字典类型                                            |
| `erp_dict_data`  | `ErpDictData`   | 字典数据                                            |
| `erp_notice`     | `ErpNotice`     | 公告通知                                            |
| `erp_user`       | `ErpUser`       | 用户                                              |
| `erp_oper_log`   | `ErpOperLog`    | 操作日志                                            |
| `erp_logininfor` | `ErpLogininfor` | 登录日志                                            |

主键：`erp_menu.menu_id`、`erp_config.config_id`、`erp_dict_type.dict_id`、`erp_dict_data.dict_code`、

`erp_notice.notice_id`、`erp_user.user_id`、`erp_oper_log.oper_id`、`erp_logininfor.info_id`

—— 全部 `BIGINT AUTO_INCREMENT`（`ErpMenu` 的 `parentId` 同样为数值型）。

## 3. 时间字段约定



* 存储值统一为 `yyyy-MM-dd HH:mm:ss` 字符串（不使用毫秒时间戳）；

* 实体字段：`Date` 类型 + `@JsonFormat(pattern = BeanCodec.DATE_TIME_PATTERN)`：



```
/\*\* 更新时间 \*/

@JsonFormat(pattern = BeanCodec.DATE\_TIME\_PATTERN)

private Date updateTime;
```



* 业务实体继承 `BaseEntity`（自带 createTime/updateTime/createBy/updateBy/remark），

  写入时由存储层自动填充。

## 4. 初始化数据

### YAML 模式

`data/*.yml` 按表名对齐实体（字段驼峰 → 小写下划线），例如 `erp_menu.yml` 内含内置菜单

（仪表盘、系统管理、用户管理、菜单管理、字典管理、参数设置、公告通知、日志管理等约 40 条）。

### SQL 模式

`mcerp-init.sql` 包含：



* 8 张表的 `CREATE TABLE IF NOT EXISTS`；

* 初始数据（与 YAML 端对齐，ID 为自然数依次排布，可重复执行）。

## 5. 附属模块的数据初始化（SoysExpansion 能力）

附属 ERP 插件（`McerpExpansion`）可覆写以下钩子提供自己的初始化数据，

由主插件内置事务执行并带 meta 幂等：



| 钩子                | 说明                                            |
| ----------------- | --------------------------------------------- |
| `dataRoots()`     | 返回资源目录名数组（如 `{"data"}`），其中 `*.yml` 释放到主插件数据目录 |
| `sqlRoots()`      | 返回 SQL 资源目录名数组                                |
| `seedData()`      | 返回 `List<Object>` 种子实体列表（运行时插入）               |
| `schemaVersion()` | 数据版本号，用于升级迁移                                  |
